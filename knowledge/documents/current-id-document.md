# Current Identity Document

## What This Is

Whichever identity document the citizen currently holds — a Căn cước card, an older CCCD card, or an even older CMND (Chứng minh nhân dân) booklet. Required for renewal and replacement; not applicable for first issuance (see `birth-certificate.md` instead) or for reissue after loss (the document is, by definition, unavailable — see `loss-declaration.md`).

## Notes

- Format and generation vary by when it was issued; the receiving agency is expected to accept any prior valid generation as long as it is genuinely the citizen's own document.
- For renewal specifically, this document confirms the identity being renewed — it does not need to still be technically valid (that's the entire reason renewal is needed).

## Assumption Made

This pack assumes agencies can look up prior issuance in the national population database even when this physical document is damaged or partially illegible, reducing (but not eliminating) reliance on the physical document alone. Current implementation completeness is unverified.
